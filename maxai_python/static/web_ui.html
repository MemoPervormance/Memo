🖱 Input Backend

Wähle das Maus-Backend. Ändert sich beim nächsten Loop-Start (■ Stop → ▶ Start).

SendInput
Windows API. Funktioniert in Borderless-Window Spielen. Kein Extra-Hardware nötig.
Logitech G-Hub
Logitech G-Hub HTTP API. Braucht G-Hub installiert + kompatible Maus.
Arduino Leonardo
Arduino/Pro Micro über USB-Serial. Erscheint als HID Maus.
KMBOX Net
KMBOX Net UDP. Hardware KVM Switch Maus-Emulator.
MAKCU
MAKCU ESP32-S3 über USB-Serial. Günstiger Arduino-Ersatz.
RP2040 / RP2350
Raspberry Pi Pico als HID Maus. Sehr niedriger Latenz.
Titan Two
Titan Two ConsoleTuner Serial-Interface.
Kernel Driver
Windows Kernel-Level Maus (Interception). Stärkste Tarnung.
